# HW0 data

The Fall 2026 tennis-court dataset is not yet committed.

Before release, document:

- source image and usage permission;
- pixel correspondences for the court plane and 3D landmarks;
- regulation court dimensions and the chosen world-coordinate convention;
- camera calibration or calibration procedure;
- stereo pair, intrinsics, extrinsics, and expected disparity direction;
- downloadable archive URL and SHA-256 checksum.

The environment check and public tests can run without these assets.
