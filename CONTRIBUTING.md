# Contributing

Bug reports and focused fixes are welcome.

## Report a bug

Open an issue with:

- the homework and task number;
- the exact command you ran;
- the expected and observed behavior;
- your operating system and Python version;
- a minimal error message or reproducible example.

Do not post assignment solutions, solution fragments, or private course data in issues.

## Submit a fix

1. Fork this repository to your GitHub account.
2. Create a focused branch in your fork.
3. Make the smallest change that fixes the problem.
4. Run the homework environment check and public tests.
5. Open a pull request against `shenlongwang/cs498-fall2026:main` and link the relevant issue.

Pull requests that disclose solutions or weaken assignment checks will be closed.
